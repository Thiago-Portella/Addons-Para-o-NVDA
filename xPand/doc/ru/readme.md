## 🚀 Обзор

**Разблокируйте невероятную скорость печати с xPand!** Созданный по образу легендарной автозамены Microsoft Word, xPand приносит эту мощь во всю среду NVDA. Создавайте неограниченное количество сокращений, которые мгновенно превращаются в целые фразы. **Если вы можете это напечатать, xPand может это развернуть!**

---

## ⌨️ Горячие клавиши

* **CTRL + F3 (Одинарное нажатие):** Мгновенно открыть диалог автозамены xPand.
* **CTRL + F3 (Двойное нажатие):** Открыть командный центр (Настройки xPand).

---

## 💡 Как использовать

Начать очень просто. Мы добавили тестовый код **«hw»**, чтобы вы могли сразу ощутить магию.

### Почувствуйте скорость
Нажмите **CTRL + F3**, введите **«hw»** и нажмите **Enter**. Диалог исчезнет, а фраза «Hello World» мгновенно появится в документе. Продуктивность на грани фантастики!

### Управляйте своей эффективностью
Дважды нажмите **CTRL + F3**, чтобы войти в настройки:

* **Список кодов:** Ваш личный словарь скорости. Быстрый переход по нажатию клавиши.
* **Полный контроль:** Правый клик для добавления, редактирования или удаления записей.
* **Простая настройка:** Введите код и фразу, нажмите **«Добавить»** и услышьте «Add succeeded».
* **Легкое обновление:** Выберите код, нажмите **«Изменить»**, внесите правки и снова нажмите **«Добавить»**.
