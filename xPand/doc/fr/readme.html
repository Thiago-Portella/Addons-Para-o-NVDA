xPand

Auteur : 'chai chaimee

Aperçu

Boostez votre productivité avec xPand ! Inspiré par l'AutoCorrection de Microsoft Word, xPand déploie cette puissance sur tout votre NVDA. Créez des raccourcis illimités qui se transforment instantanément en phrases complètes. Si vous pouvez le taper, xPand peut l'étendre !


Touches de Raccourci

CTRL + F3 (Simple appui) : Ouvre instantanément le dialogue AutoCorrect de xPand.

CTRL + F3 (Double appui) : Accédez au centre de configuration de xPand.


Mode d'emploi

C'est un jeu d'enfant. Utilisez le code « hw » pour tester la magie dès maintenant.

Vivez l'expérience de la vitesse :
Appuyez sur CTRL + F3, tapez « hw », puis Entrée. Le dialogue disparaît et « Hello World » s'insère instantanément. C'est magique !

Personnalisez vos succès :
Double-cliquez sur CTRL + F3 pour les réglages :

  • Liste des Codes : Votre bibliothèque de vitesse. Naviguez d'une simple touche.
  • Contrôle Total : Clic droit pour ajouter, modifier ou supprimer vos raccourcis.
  • Installation Rapide : Entrez votre code, votre phrase, cliquez sur Ajouter et écoutez « Add succeeded ». Vous êtes prêt !
