Windows 应用增强

  • 作者：Joseph Lee、Derek Riemer 等

注意：此插件最初称为 Windows 10 应用增强，在 2021 年更名为 Windows 应用增强，以支持 Windows 10 和 Windows 11 等后续版本。此插件的部分内容仍将引用原始插件名称。

此插件是用于各种现代 Windows 应用的应用模块集合，以及对 Windows 10 及更高版本中某些控件的增强和修复。

注意:

  • 此插件需要 64 位 Windows 10 22H2（内部版本 19045）、11 23H2（内部版本 22631）或更高版本。
  • 功能更新支持期限与消费者支持期限（家庭版、专业版、专业教育版、工作站专业版）相关联，并且插件可能会在消费者支持结束之前终止对功能更新的支持。有关更多信息和支持日期，请参阅 https://aka.ms/WindowsTargetVersioninfo。
  • 尽管可以安装，但此插件不支持 Windows Enterprise LTSC（长期服务版）和 Windows Server 版本。
  • Not all features from Windows Insider Preview builds will be supported, more so for features introduced to a subset of Windows Insiders.

有关每个版本之间所做的具体更改，请参阅另外发布的更新日志文档。
