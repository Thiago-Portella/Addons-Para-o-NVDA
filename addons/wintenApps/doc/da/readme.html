Vigtige forbedringer til Windows apps (Windows App Essentials)

  • Forfattere: Joseph Lee, Derek Riemer og andre

Bemærk: Denne tilføjelse hed Windows 10 App Essentials, men er blevet omdøbt til Windows App Essentials i 2021 for at understøtte Windows 10 og fremtidige udgivelser som Windows 11. Dele af dette tilføjelsesprogram vil stadig henvise til det originale navn for tilføjelsen.

Denne tilføjelse er en samling af app-moduler til forskellige Windows-apps, samt forbedringer og rettelser for visse windows 10 kontrolelementer.

Bemærkninger:

  • Denne tilføjelse kræver Windows 10 22H2 (build 19045), 11 23H2 (build 22631) eller nyere udgivelser.
  • Varigheden af understøttelse af funktionsopdateringer er bundet til varigheden af forbrugersupport (Home, Pro, Pro Education, Pro for Workstations-udgaver), og tilføjelsen kan afslutte understøttelsen af en funktionsopdatering, før forbrugersupporten ophører. Se https://aka.ms/WindowsTargetVersioninfo for mere information og supportdatoer.
  • Selvom installation er mulig, understøtter denne tilføjelse ikke Windows Enterprise LTSC (Long-Term Servicing Channel) og Windows Server-udgivelser.
  • Not all features from Windows Insider Preview builds will be supported, more so for features introduced to a subset of Windows Insiders.

For en liste over ændringer, der er fremstillet mellem hver udgivelse af tilføjelsen, henvises til ændringslog for tilføjelsen.
